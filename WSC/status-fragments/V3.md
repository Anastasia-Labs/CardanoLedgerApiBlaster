## 5. Open issues and honest limits

1. **The P4 disjunction is proved SHAPE BY SHAPE.** A shape fixes the redeemer's
   constructor tag and the tag selects the arm, so four theorems over four
   pairwise-disjoint shape classes is strictly weaker than one theorem over a
   symbolic redeemer. Making the tag symbolic re-introduces exactly the branch
   structure shaping removes. This is SHAPING-RESULTS §7's shape-coverage gap and
   it is **not closed**.
2. **`noEscape` is proved for a FIXED OUTPUT COUNT (two).** The scan is a `pall`
   over a list whose length the shape fixes. A statement for all output counts
   needs an induction the shaped layer cannot express.
3. **P6 exercises only the SINGLE-ASSET containment path.**
   `poutputsContainExpectedValueAtCred` dispatches on the expected value's shape
   (ProgrammableLogicBase.hs:678-701): one asset takes
   `hasAtLeastAssetInProgOutputs`, anything else takes the wholesale /
   `pvalueContains` builtin path. SHAPE G6 has one `(cs, tn)` pair, so **the
   multi-asset path is untested at UPLC.** That is the single most valuable next
   shape.
4. **The delegating arms are delegation theorems only.** DT1 proves the global
   transfer validator RUNS; DS1 proves a `SeizeAct` scoped to this policy's node
   exists. What those validators then enforce is P1 / P2, neither of which is
   proved at UPLC. **`Local` is the only arm whose custody content is presently a
   bytecode theorem.**
5. **P1 and P2 remain unshaped.** P6's budget discovery is directly relevant:
   the transfer goldens need K = 3,262 / 3,726 and seize K = 2,570, all above
   G6's 2837, and shaped prep is budget-independent, so the prep barrier is gone —
   but P6's experience says the *vacuity floor* must be measured first, not
   guessed.
6. **E1 unchanged.** Every theorem is about `cekExecuteProgram … K`. The bridge to
   a real node's ExUnits budget is `LR_BUDGET_minting` / `LR_BUDGET_global` in
   `WSC/Honest.lean`, undischarged.
7. **E11 unchanged.** The global validator's flat decodes only against the
   unpushed PCB branch `cip153-value-builtins`.
